# 风语 — 开发说明

## 项目概况

风语是一款 Windows 桌面测风数据自动化工具，自动从网易邮箱下载 NRG .rld 原始数据，调用 SymphoniePRO Desktop 解密为可读 .txt 格式。

- **语言**：Python 3.11
- **界面**：PyQt5
- **打包**：PyInstaller → 单文件 .exe

## 项目结构

```
D:\WindWatcher\
├── main.py                      ← 入口
├── config.json                  ← 用户配置文件（与exe同目录）
├── build.bat                    ← 打包脚本
├── core/                        ← 核心引擎（无界面依赖）
│   ├── __init__.py
│   ├── config_loader.py         ← 读取config.json + Excel表格
│   ├── executor.py              ← 任务编排：检测→下载→转换
│   ├── email_fetcher.py         ← POP3邮箱登录/扫描/下载
│   ├── integrity_checker.py     ← 本地数据完整性检查
│   └── converter.py             ← .rld解密转换（nrgpy + 合并）
├── ui/                          ← 界面层
│   ├── __init__.py
│   └── main_window.py           ← 主窗口 + 所有面板 + 角色栏
└── resources/                   ← 静态资源
    ├── icons/
    │   ├── characters/          ← 12个角色头像
    │   └── quotes.txt           ← 角色台词库
    └── themes/                  ← QSS主题文件
        ├── fanren_xiuxian.qss   ← 念头通达（默认）
        ├── dark_tech.qss        ← 暗夜科技
        ├── ocean_blue.qss       ← 浅紫天蓝
        ├── clean_light.qss      ← 极简亮色
        └── lingcage.qss         ← 枫叶银杏
```

## 核心模块说明

### config_loader.py
- `Config()` 类：读取 `config.json` 和 Excel 表格
- `get_tower_list()`：从华南测风塔总表读取有效塔
- 列索引：A=编号, B=项目, J=起始时间, N=备注, O=解析密码, Q=塔号

### email_fetcher.py
- `EmailFetcher` 类：POP3邮箱操作
- `filter_by_date()`：从最新邮件倒序扫描，到目标范围外自动停
- `download_attachments()`：匹配塔号前缀下载附件
- 超时：单操作30秒，总扫描30分钟上限

### converter.py
- `RldConverter` 类：调用 nrgpy 调 SymphoniePRO Desktop
- 输出到临时目录 → 合并筛选 → 移到 `TXT输出/` 子目录
- 文件名：`{编号}_{开始日期}_{结束日期}_combined.txt`

### executor.py
- `TaskExecutor` 类：完整任务编排
- 流程：完整性检查 → 判断缺哪些 → 按需下载 → 批量转换

## 界面结构

### MainWindow（main_window.py）
- 菜单栏：文件/设置/帮助
- 设置 → 主题风格（5个QSS主题）
- 设置 → 使用和开发说明（弹窗文档）
- 3个标签页：数据任务 / 配置 / 定时任务
- 角色按钮栏：12个72×72按钮 + 悬停台词气泡
- 日志面板：深色终端风格

### TaskPanel
- QTreeWidget 显示项目→塔的树形结构
- 全选复选框
- 日期选择器 + 快捷按钮
- 完整性检测 → 执行任务

### ConfigPanel
- 邮箱授权码、Excel路径、数据目录、SymphoniePRO路径
- 浏览按钮 + 保存配置

### SchedulePanel
- 每月几号几点执行
- 数据范围选择
- Windows 任务计划程序集成

## 修改指南

### 新增主题
1. 复制 `resources/themes/` 下一个 `.qss` 文件作为模板
2. 修改颜色值
3. 在 `main_window.py` 的 `themes` 列表中添加条目

### 新增角色图标
1. 将 64×64 PNG 放入 `resources/icons/characters/`
2. 在 `main_window.py` 的 `name_map` 中添加文件名→中文名映射
3. 在 `quotes.txt` 中添加该角色的台词

### 新增项目/塔
无需改代码，在华南测风塔总表中添加新行即可。

### 修改Excel列索引
在 `config_loader.py` 的 `get_tower_list()` 中修改对应列号。

## 打包

```bash
pyinstaller --onefile --windowed --name="风语" \
  --add-data="resources;resources" --hidden-import=nrgpy main.py
```

输出在 `dist/风语.exe`。将 `config.json` 一同复制即可分发给用户。

## 注意事项
- 打包前确保 `dist/` 清空，否则可能权限冲突
- 必须使用 Hermes venv 中的 Python（3.11），系统Python缺少PyQt5
- nrgpy 需要在有 SymphoniePRO Desktop 的电脑上才能解密
- 配置文件 `config.json` 不打包进exe，用户可自行修改
